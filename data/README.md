# Dataset

The Smart MCQ Solver Challenge dataset was provided through the Kaggle competition.

## Dataset size

- Training set: 2,000 rows
- Test set: 500 rows

## Training columns

`id`, `prompt`, `A`, `B`, `C`, `D`, `E`, `answer`

## Test columns

`id`, `prompt`, `A`, `B`, `C`, `D`, `E`

## Data quality checks

The supplied files were checked during project preparation:

- Missing values: 0
- Duplicate rows: 0

## Correct-answer distribution

- A: 369
- B: 490
- C: 459
- D: 358
- E: 324

The original competition CSV files are intentionally not stored in this public GitHub repository. They were supplied through the Kaggle competition.
